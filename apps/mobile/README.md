# ATHLETE Mobile

Aplicación móvil inicial para iOS y Android construida con Expo, React Native, TypeScript y Expo Router.

Desde la raíz del monorepo:

```sh
npm install
npm run mobile
```

`npm run ios` y `npm run android` inician Expo apuntando al simulador/dispositivo correspondiente. Los datos de las pantallas actuales son demostrativos; no hay autenticación ni servicios remotos conectados.
