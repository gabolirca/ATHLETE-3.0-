# Informes de auditoría

Esta carpeta conserva los informes originales del agente responsable.

Los informes son evidencia histórica de las inspecciones realizadas.

Reglas:

- No sobrescribir informes anteriores.
- Conservar fecha y agente.
- Diferenciar hallazgos confirmados de hipótesis.
- No considerar cifras históricas como datos actuales sin verificación.
- Registrar cualquier corrección mediante un informe nuevo.
